# NovelEditor 使用说明

## 启动

安装包：`artifacts/release/NovelEditor Setup 0.1.0.exe`（或直接运行 `artifacts/release/win-unpacked/NovelEditor.exe`）。

数据目录默认 `H:\\NovelEditor工程\\data`，可用环境变量 `NOVELEDITOR_DATA_DIR` 覆盖；应用设置（含 AI API 配置）存于该目录的 `settings.json`。

## 基本流程

1. **书架**：点「新建书籍」输入书名/作者/简介；点卡片进入编辑器；卡片右上「⋮」可删除书籍。
2. **大纲计划**：最左侧「大纲计划」板块书写全书大纲、卷章规划与创作计划（Markdown，独立于章节内容，随本书保存，切书自动冲刷）。
3. **章节**：原「大纲」面板已改名「章节」，管理卷与章（卷/章「⋮」菜单：新建章节、重命名、删除、拖拽排序）。
4. **写作**：中间 Markdown 源码编辑，右侧实时预览；顶栏可切「分屏 / 预览」，分屏分隔条可自由二维拖动。
5. **文字工具栏**：位于所有版块顶部，统一作用于**当前聚焦**的可编辑版块（大纲计划 / 章节正文）——标题、加粗、斜体、引用、列表、链接、图片、分隔线、撤销/重做。
6. **保存**：自动保存（30 秒）与手动 Ctrl/Cmd+S；出现"存在冲突"提示时可选择用本地覆盖或放弃本地。
7. **查重**：顶栏「查重」全书检测（后台运行，进度显示在顶栏）；完成后右侧「查重报告」列出命中，点击可跳转高亮位置；可「忽略」单条命中（重跑后保留忽略状态）。
8. **搜索 / 导出 / 备份**：顶栏对应按钮；导出支持 章/卷/全书 × TXT/MD/DOCX；备份为 VACUUM INTO 快照（保留 5 份）。

## AI 助手（需自备大模型 API）

右下角 **⚡ 悬浮按钮** 打开 AI 抽屉：

- 选中文字后点「一键润色 / 一键扩写 / 一键精简」；
- 或输入要求（可带选中参考文字）点「发送」，让 AI 直接写作；
- 结果可「替换选中 / 插入光标处 / 复制」。

调用为 **OpenAI 兼容接口**（DeepSeek、Kimi、通义千问、OpenAI、Ollama 等均可）：在「设置 → AI 助手」填 API 地址、密钥、模型名即可；地址会自动兼容三种写法（完整 `/chat/completions`、`/v1` 结尾、裸域名），404 时自动回退候选。

**形象提示词**：内置「小说作家 / 文字润色 / 大纲策划 / 对白教练」四种形象，每次调用都把当前选中形象作为 system 提示词发送；可在设置中增删改、切换当前形象。

## 设置（顶栏「设置」，三页签收纳）

- **AI 助手**：API 地址 / 密钥 / 模型 + 形象提示词管理。
- **外观**：界面语言（简体中文 / English）、明暗主题、写作/阅读背景（内置单色 + 自定义图片）。
- **查重参数**：n-gram 长度 n、winnowing 窗口 w、最小片段字数、近似阈值、bad/warn 占比阈值。

## 查重分级

- bad（红"重"）：≥100 字连续近似重复，或重复占比 ≥5%。
- warn（橙"疑"）：≥2 处短命中，或占比 1%~5%。
