# NovelEditor 使用说明

## 启动

安装包：`artifacts/release/NovelEditor Setup 0.1.0.exe`（或直接运行 `artifacts/release/win-unpacked/NovelEditor.exe`）。

数据目录默认 `H:\\NovelEditor工程\\data`，可用环境变量 `NOVELEDITOR_DATA_DIR` 覆盖。

## 基本流程

1. **书架**：点「新建书籍」输入书名/作者/简介；点卡片进入编辑器；卡片右上「⋮」可删除书籍。
2. **写作**：左侧大纲管理卷与章（卷/章的「⋮」菜单：新建章节、重命名、删除）；中间 Markdown 源码编辑，右侧实时预览；顶栏可切「分屏 / 预览」。
3. **保存**：自动保存（30 秒）与手动 `.Ctrl/Cmd+S`；出现"存在冲突"提示时可选择用本地覆盖或放弃本地。
4. **查重**：顶栏「查重」全书检测（后台运行，进度显示在顶栏）；完成后右侧「查重报告」列出命中，点击可跳转源码高亮位置；可「忽略」单条命中（重跑后保留忽略状态）。
5. **搜索**：顶栏「搜索」输入关键词，点击结果跳转。
6. **导出**：选择 章/卷/全书 粒度与 TXT/MD/DOCX 格式，选保存路径。
7. **备份**：立即备份或从历史快照恢复（恢复会覆盖当前书数据库）。

## 查重参数

顶栏「查重设置」可调：n-gram 长度 n、winnowing 窗口 w、最小片段字数、近似阈值、bad/warn 占比阈值。

- bad（红"重"）：≥100 字连续近似重复，或重复占比 ≥5%。
- warn（橙"疑"）：≥2 处短命中，或占比 1%~5%。
