# NovelEditor 优化建议报告

> 记录日期：2026-10-11

> 来源：用户在 v0.1.0 交付后的反馈（附界面截图与查重报告截图）。

## 1. 插入图片改为系统文件选择器

**现状**：工具栏「插入图片」需要手动输入/粘贴地址，方式不够简明。

**建议**：
- 点击后直接调用操作系统资源管理器（Electron `dialog.showOpenDialog`）选择本地图片；
- 支持常见图片格式：`.png`、`.jpg`、`.jpeg`、`.gif`、`.webp`、`.bmp`、`.svg`；
- 选中后插入 `![alt](相对/绝对路径)`，可选：同时把图片复制到书目录 `assets/` 下以保证便携；
- 支持多选一次性插入多张。

**涉及模块**：`main/ipc.ts`（新增 dialog:selectImages 通道）、`main/services/exportService.ts`（DOCX 导出需内嵌图片）、渲染层工具栏按钮。

## 2. 预览渲染的 Markdown 段落规则不符合预期

**现状**（两个问题，均出在 markdown-it 的默认规则）：
1. **行首空格不识别**：源码里行首的缩进空格（如全角空格或 4 空格）在预览中被吞掉/不显示，理想显示效果（保留缩进）做不到；
2. **单回车不分段**：单个回车被当作行内软换行，必须空一行才分段，写作时手感差。

**建议**：
- 方案 A（推荐）：markdown-it 配置 `breaks: true`（`new MarkdownIt({ breaks: true }`），单回车即换行 `<br>`，符合写作直觉；
- 方案 B：行首缩进保留——渲染前把行首空格替换为 `&nbsp;`，或对正文段落开启 `white-space: pre-wrap` 的定制渲染；
- 注意导出（TXT/DOCX）不受影响：导出走 `contentText` 纯文本，与预览规则解耦；
- 需同步更新查重的归一化逻辑评估：预览规则变化不改变源码，但要确认 plain_map 映射仍 1:1。

**涉及模块**：`renderer/components/PreviewPane.tsx`、`shared/markdown/*`。

## 3. 查重精准度不足（误报）

**现状**：查重能识别出重复，但**不够精准**——报告中会把**非重复片段**判定为重复内容（见用户截图：报告摘录里混入了实际不重复的段落）。

**可能根因（待排查）**：
- 近似重复链串联（`chainFrags`）把同章节内相邻但不同源的片段串成一条，`diceBigrams ≥ 0.85` 误判为 near；
- 分桶偏移容忍（`gapA/gapB ∈ [-2,15]`、`|gapA-gapB| ≤ 4`）过宽，把公共常用句式（开头套话、过渡句）卷入；
- 命中区间展示取了 chain 的 span 两端，实际只有中间部分重复，**区间过大**导致摘录含非重复内容；
- 评分阈值 `MIN_FRAG_LEN=30`、`nearThreshold=0.85` 对短章/常用句偏松。

**建议方向**：
- 命中区间收缩到真实公共子串（不要用 chain 的整体 span），保证报告摘录逐字可验证；
- 提高 near 判定的连续性要求（如要求 ≥80% 覆盖的连续匹配，而非 bigram 松弛）；
- 过滤高频公共 n-gram（IDF 加权 / 停用片段表）；
- 为误报案例补黄金测试用例（Vitest），先复现再调参。

**涉及模块**：`shared/checker-core/detect.ts`（chainFrags/extend）、`score.ts`、`tests/detect.test.ts`。

## 4. 一键回退按钮（本次会话级撤销历史）

**现状**：撤销仅限编辑器内部 Ctrl+Z，没有界面入口，且跨章节/跨操作的历史不可回退。

**建议**：
- 界面加一个 **← 回退按钮**（建议放工具栏左侧或标题栏旁）；
- 点击后直接恢复到上一步状态（内容、当前章节等）；
- **范围仅限本次启动软件**：回退操作缓存存内存（或临时文件），**关闭软件即清除**，不持久化。

**涉及模块**：渲染层 store（记录每次保存/切换的操作快照栈）、工具栏按钮；注意与编辑器内生 Ctrl+Z 的关系（建议按钮回退的是"应用级操作"：保存、切章、批量编辑）。

---

## 5. 界面语言：简体中文 / 英文可切换

**现状**：全界面硬编码简体中文。

**建议**：
- 引入轻量 i18n（如 `i18next` + `react-i18next`，或自建字典），所有 UI 文案抽 key；
- 默认简体中文，设置项可切换 **English**；
- 只做这两种语言，不做繁体等中间态；
- 设置持久化到 localStorage（与布局设置同级）。

**涉及模块**：全局——TopBar/OutlinePanel/ReportPanel/四个 Modal/书架页/状态栏全部文案。

| # | 项目 | 预估工作量 | 优先级 |
|---|------|-----------|--------|

## 验收口径（每项落地时的完成标准）

1. 图片：点击→资源管理器选图→插入成功，常见格式可预览；
2. 预览：单回车分段显示、行首缩进可见，且与导出内容一致；
3. 查重：对报告中每个命中，摘录区间逐字与两章原文一致，无非重复段落混入；补 ≥3 个误报回归用例；
4. 回退：点击 ← 恢复上一步，重启软件后回退栈为空；
5. 语言：切换 EN 后全界面无残留中文（或反之），选择随启动保留。
